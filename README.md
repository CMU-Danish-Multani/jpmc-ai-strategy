# JPMorgan Chase AI Strategy: team dashboards

Working materials for 94-804 AI Strategy at Carnegie Mellon Heinz College.

Two interactive pages, built from public evidence only, current through 2026-08-28.

- `verticalDecision.html` compares the two candidate strategy verticals side by side.
- `jpmcFactbook.html` is a searchable reference of every figure the team can cite.
- `index.html` links both.

## Running it

No build step and no dependencies. Open `index.html` in any browser, or serve the folder:

    python3 -m http.server 8000

Then visit http://localhost:8000

## A note on the evidence

Every claim carries a label saying how sure we are and where a number came from. Numbers were
checked by reviewers instructed to refute rather than confirm. Nothing here is confidential or
non-public information about any company.
